# Bio Template post

An unpublished post in the Biography Directory blog. Editors duplicate it to start a new bio.
Drafts never appear in the directory, so the template stays hidden.

## Set-up (once)

1. Pages → Biography Directory → **+** (new post).
2. Title: `Bio Template`.
3. Add one **Text** block and paste the content below.
   The Bio details lines must be the first paragraph. Separate them with **Shift+Enter**
   (plain Enter also works; the page joins them back together).
4. Leave the post as a **Draft**. Do not publish it.

## Text block content

```
Years: 1920–1999
Branch: Army
Conflict: World War II
Cemetery: West Virginia National Cemetery
Rank: Sergeant
Written by: First Last and First Last
School: School Name
Instructed by: First Last
Section: 5
Site: 123
Interment date: January 1, 1999
PDF: Download the PDF

Start the biography here. Replace this paragraph.
```

After pasting:

- Don't add a Sources section. Every bio page links to the shared source citations document automatically
  (decision Nov 19); send new citations to whoever maintains that document.
- Link the words `Download the PDF` to the uploaded PDF (Link → File). Delete the PDF line if there is no PDF.

## Rules for each line

| Line | What to enter |
| --- | --- |
| Years | Birth and death years with a dash: `1920–1999` |
| Branch | One or more of: Army, Navy, Marine Corps, Air Force, Coast Guard. Separate with commas. Air Force covers the Army Air Corps; Coast Guard covers the Merchant Marine. |
| Conflict | One or more of: World War I, World War II, Korean War, Vietnam War, Persian Gulf War, Iraq War, War on Terror. Separate with commas. |
| Cemetery | Grafton National Cemetery or West Virginia National Cemetery |
| Rank | As written in the bio. Two veterans or two ranks: separate with ` / ` |
| Written by / School / Instructed by | Student authors, school, teacher. Delete any line that doesn't apply. |
| Section / Site | Grave location. Or use one `Grave:` line instead for other formats. |
| Interment date | Optional. |
| PDF | `Download the PDF`, linked to the file. |

Spell Branch, Conflict and Cemetery values exactly as listed: the directory filters use them.
A new value (for example a new conflict) needs a quick code update first; ask Dodd Web Co.

## Photos

Add an **Image** block where the photo belongs, with **caption on**.
Caption: what the photo shows, then the credit in italics, e.g. *Library of Congress*.
The bio page adds the green frame and caption bar automatically.

## When it appears

Publish the post. The directory picks it up overnight (the index rebuilds daily),
or ask Dodd Web Co to run the update right away.
